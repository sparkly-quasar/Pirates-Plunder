# Battle Royale
- **Battle Royale** (Multiplayer -> Battle Royale). Every crew for itself on a big island, and each player brings the crew they've trained in single player, whole: no limits, just trained crews against each other. No crew yet? You bring ten fresh recruits.
- **Rounds.** A Battle Royale is 1, 3 or 5 rounds; the most rounds won takes it. Between rounds there's the usual coaching, for that Battle Royale only: it never changes your saved crew.
- **Vega** sails only in the final round, unless whoever sets it up ticks "Vega may sail every round".
- **On a server or hosted yourself.** On a server, choose Battle Royale in a new game's settings (the server list says when a game is one). Or host one from this computer for up to three friends. Computer crews can fill empty seats, fresh.
- **Fair crews.** The server (or host) checks every crew that arrives against the coaching limits, so an edited save can't bring super-sailors.
- **Servers on Apple Silicon Macs:** the package's Docker Compose file now builds the right kind of image by itself (`platform: linux/amd64`). SERVER.md also explains how to check the phone WebSocket paths by hand.
- Everyone needs 0.14.0 to play together. Copies from 0.6.1 on update from a friend or a server (or press **Check for Updates** on the Play on a Server screen).
