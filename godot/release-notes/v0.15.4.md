# On a phone, Scoreboard sits under Menu; servers in Docker restart for an update
- **On a phone, the Scoreboard button sits under Menu**, not beside it, so it no longer covers the end of the line along the top. Down the right edge: Menu, Scoreboard (with three or four crews), the turn clock (in games with a turn limit), then the scoreboard itself when it's open.
- **A server in Docker restarts its container to update**, instead of swapping the server inside the running container. After a self-update, Docker Desktop could stop passing on the server list's port (UDP 24681), so players' server lists stopped finding the server until the container was restarted. Now the server stops, Docker starts the container again (`restart: unless-stopped`, already in docker-compose.yml), and it comes up on the new version. A new version that doesn't start is forgotten, and the next start uses the image's own. Servers run with systemd still switch in place.
- **To get this, a Docker server needs one rebuild from the 0.15.4 package**, in a fresh folder (see "Put it on a server" in SERVER.md): an image built from an older package keeps its old `run.sh`. Until then, `docker compose restart` after a self-update brings the server list back.
