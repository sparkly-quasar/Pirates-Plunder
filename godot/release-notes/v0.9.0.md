# back in after a dropped connection, and browsers on servers

- **Get back into your crew.** If your connection drops partway through an online match (the Wi-Fi blinks, the laptop sleeps, the game crashes), the computer sails your crew while you're away, and you get it back when you return. Your game reconnects by itself for two minutes; after that, **Rejoin Your Crew** on the Play on a Server list takes you back in. Mid-game you land on the island exactly as it stands; between games you go to the coaching. It works on a server and in a friend's hosted game.
- **A server waits for you.** If every player drops, the match waits for them, paused, for three minutes (`rejoin-seconds`), and the computer's crews don't move meanwhile. Leaving on purpose (back to the menu) isn't waited for.
- **Play in a web browser (early).** A server now also lets in players whose game runs in a browser, on WebSockets, at the same time as the Mac and Windows copies, in the same lobby and match. For now it plays with a mouse and keyboard, and the web page is served separately; touch controls for phones, and the page in the server package, come next. See `godot/SERVER.md`.
- **Servers:** the Docker files now also open TCP ports **24680** and **24681**, for browsers. New settings: `web-port` and `rejoin-seconds` (see `godot/SERVER.md`).
- Everyone needs 0.9.0 to play together. Copies from 0.6.1 on update from a friend or a server; older ones need this download.
