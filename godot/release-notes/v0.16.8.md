# A new look for the menus
- **Every screen off the island has a new look:** the main menu, setting up a game, coaching, Your Crew, the results, the campaign, the server list and the lobby. Panels and buttons are edged in brass, the words are the colour of old parchment, and a sea chart with a compass rose lies behind it all.
- **The game's name is hand-lettered,** and headings are set in an old printer's type. Everything you read is in a clear, open typeface (Fira Sans) that stays easy to read on a phone.
- **The main thing to do on each screen is a gold button:** Start Expedition, Set Sail, Done, Next Expedition, Play Again.
- **Buttons feel like buttons:** they light up under the mouse, press in when clicked, and the one the keyboard is on has a gold ring.
- The island itself looks just as before.
