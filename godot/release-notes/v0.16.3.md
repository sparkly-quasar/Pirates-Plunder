# Scrolling with a finger on phones
- **On a phone, every list scrolls with your finger, wherever you drag it.** On the coaching screen (and the campaign, the server list and the other long screens), a drag that starts on a button now scrolls the list instead of getting stuck, and the button doesn't fire. A plain tap still presses it, and a quick flick keeps the list gliding for a moment. On a computer nothing changes.
