# a simpler main menu; a loading screen on phones
- **A simpler main menu.** It now asks only how you want to play: **Single Player**, **Multiplayer** or **Settings** (and **Continue** when you have a saved game). Each opens its own page: Single Player has Against the Computer and Practice Alone; Multiplayer has Play on a Server, Play Direct (Host / Join), Players Sharing One Computer and Continue Online Match. **Back** (or Esc) returns, and coming back from a screen lands on the page you left.
- **Settings:** your name (what other players see on a server), the volume, and the layout: Automatic, Phone (big buttons, touch) or Computer (mouse and keys).
- **A loading screen in the browser.** On a phone the game no longer starts on a blank page: you see the game's name and a progress bar while it downloads, then "Getting the ship ready" while the phone prepares it. The first time takes a minute on a phone; after that it starts much faster.
- On a phone, **Play on This Server** is still the first button. If the page was opened at a plain http:// address, it now says so plainly and how to fix it (phones need the server's https:// address, see "HTTPS with Tailscale" in `godot/SERVER.md`).
- The game opens on a plain dark screen instead of the Godot logo.
- Everyone needs 0.11.0 to play together. Copies from 0.6.1 on update from a friend or a server.
