# phones over HTTPS; servers keep saved games under Docker
- **Phones need HTTPS.** Opened from a phone at `http://…:24682/`, the game stopped with "Secure Context - Check web server configuration (use HTTPS)": browsers only run it on a secure page. Put the server behind `tailscale serve` (three commands, in `godot/SERVER.md` under **HTTPS with Tailscale**) and open `https://<machine>.<tailnet>.ts.net:10000/` on the phone, with the Tailscale app on. Over HTTPS the page now connects through that same address, so the plain address works; with 0.10.0's page you had to add `/index.html`.
- **Servers in Docker now keep saved games.** The `saves` volume belonged to root while the server runs as its own user, so no game was ever saved, though the log said otherwise. New installs get a volume the server can write to. **Updating an existing Docker server:** give its volume to the server once (`docker run --rm -v server_saves:/s debian:bookworm-slim chown 10001:10001 /s`, see **Saved games** in `godot/SERVER.md`).
- The server now checks at start that it can write its saved games, and says so in its log if it can't.
- Everyone needs 0.10.1 to play together. Copies from 0.6.1 on update from a friend or a server.
