# Check for Updates; Play Direct on its own page
- **Check for Updates** on the Play on a Server screen. It asks the servers it finds whether there's a newer version and, if one has it, updates your game from that server straight away: the game downloads it, restarts and comes back to the server list, ready to start or join a game. With nothing newer it says you're up to date (and names any server that's older than you, so you know who needs updating). A server with a newer version also gets its own **Update to …** button in the list. Not in a browser: the page always loads the server's version.
- **Play Direct** is now one button on the Multiplayer page. It opens its own page with **Host a Game** and **Join a Game**; Back (or Esc) returns to Multiplayer.
- Everyone needs 0.12.0 to play together. Copies from 0.6.1 on update from a friend or a server.
